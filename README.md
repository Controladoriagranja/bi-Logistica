# Logística HTML

Dashboard da Granja Brasília com a estrutura visual dos módulos Comercial e Suprimentos.

Os dados e cálculos ficam na API autenticada. O site não contém planilhas, dados operacionais nem credenciais.

Indicadores: Controle de Frete, Performance de Ocupação, Devoluções, Ocorrências de Custo, Valores Diários, Descargas, Pallets, Valores a Pagar e Pesagem.

Referência principal: fórmulas da planilha Logística 2026. Ocupação principal usa peso bruto dividido pela capacidade; custo geral/kg usa frete dividido pelo peso bruto. Posições de pallets e títulos não são interpretadas como saldos históricos.
